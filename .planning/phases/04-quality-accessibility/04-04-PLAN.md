**Create vercel.json in the project root:**

Vite builds a single-page application. Without rewrites, direct URL access (e.g., navigating to `/weather/london`) returns a 404 from Vercel's CDN. The rewrites rule sends all routes to the built `index.html`, letting React Router (or Vite's SPA mode) handle routing client-side.

Since this app has no React Router (it's a single page with state), the rewrites rule is still best practice to prevent blank-page 404s on refresh or deep links:

```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

No other Vercel configuration is needed — Vite's `npm run build` output goes to `dist/`, which Vercel auto-detects as the output directory for Vite projects.
