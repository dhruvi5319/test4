**CurrentConditions.tsx — details grid text wrapping:**

The details grid `<div className="grid grid-cols-2 gap-3 pt-2 border-t border-slate-600">` can produce truncation at 375px if label + value text is long (e.g., "Wind  14 km/h NW").

Fix: Change each detail cell from a single `<div>` to a flex-col layout that allows the value to wrap:
```tsx
// Before (example):
<div className="text-sm">
  <span className="text-slate-400">Wind</span>
  <span className="ml-2 text-white font-medium">...</span>
</div>

// After:
<div className="text-sm flex flex-col gap-0.5">
  <span className="text-slate-400">Wind</span>
  <span className="text-white font-medium">...</span>
</div>
```
Apply this flex-col pattern to all three detail cells (Humidity, Wind, Precip). Remove the `ml-2` spacer from the value span (the gap handles spacing).

The hero temperature div `text-7xl` may be tight at 375px alongside the 72px icon. The flex row `<div className="flex items-center gap-4">` is fine — both elements fit within ~375-32(padding)=343px at these sizes.
